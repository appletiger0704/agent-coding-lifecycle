# ADR Index — 中央研究 Repository

> 此目錄尚未包含任何 **Accepted ADR**。

本 Repo 專門存放 Agent Coding Lifecycle 的研究成果與可複用模板。若將來要針對**本 Repo 自身**的工程制度作正式決策，可依 `templates/adr-template.md` 提出 `Proposed` ADR，經人工審查後再標為 `Accepted`。

## 工作原則

1. 先搜尋既有 Accepted ADR。
2. 只有對長期工程架構有重要影響時才提出新 ADR。
3. 使用 Proposed → Accepted／Rejected → Superseded／Deprecated 等狀態；狀態變更應有可追溯審核紀錄。
4. 新決策取代舊決策時建立新文件，保留舊文件的歷史內容並互相連結。
5. 實際產品的決策請放在各產品 Repo 的 `docs/adr/`，不要全部集中在此處。
